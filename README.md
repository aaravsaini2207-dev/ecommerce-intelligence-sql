🚀 E-Commerce Intelligence System (SQL)
📊 Project Overview

A full-scale business intelligence system built using SQL to analyze 100,000+ e-commerce transactions.

This project simulates how real analytics teams monitor:

Revenue growth

Customer value

Margin impact

Churn risk

Product concentration risk

🧠 Business Questions Solved

Is revenue growing consistently?

Who are the high-value customers?

How much revenue comes from repeat buyers?

Are freight costs reducing margins?

Is revenue dependent on a few products?
